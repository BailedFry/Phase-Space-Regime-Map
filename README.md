# Phase-Space Regime Map (Structural Edition)

The Phase-Space Regime Map formalises how reasoning systems occupy, stabilise within, and transition between structural regimes.  
It defines the global grammar governing:

- Regime Surfaces  
- Regime Boundaries  
- Regime Stability  
- Collapse-Driven Transitions  
- Recurrence-Driven Transitions  
- Gradient-Horizon Coupling  
- Motif-Induced Regime Shifts

- **Phase_Space_Regime_Map.pdf** — the structural edition manuscript  
- **Overleaf LaTeX source** — fully compile-ready

## Overview

The Phase-Space Regime Map is the global classifier for structural behaviour in bounded reasoning systems.  
It applies to:

- AI reasoning engines  
- Mathematical inference systems  
- Simulation architectures  
- Structural identity frameworks
